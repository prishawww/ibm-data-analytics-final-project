# IBM Data Analytics Capstone Project: Stock Analysis and Dashboard

## 📌 Project Overview
This project analyzes historical stock prices and quarterly revenue data for **Tesla (TSLA)** and **GameStop (GME)**. It uses Python to collect financial data, perform basic data processing, and create visualizations to understand stock price trends and revenue performance.

## 🎯 Objectives
- Extract historical stock data using the `yfinance` library.
- Collect quarterly revenue data using web scraping.
- Clean and process data using `Pandas`.
- Visualize stock prices and revenue using `Plotly`.
- Build dashboards for Tesla and GameStop.

## 🛠️ Technologies Used
- Python
- Pandas
- yfinance
- BeautifulSoup
- Requests
- Plotly
- Jupyter Notebook

## 📊 Project Tasks
1. Extract Tesla stock data.
2. Scrape Tesla quarterly revenue data.
3. Extract GameStop stock data.
4. Scrape GameStop quarterly revenue data.
5. Create a Tesla stock and revenue dashboard.
6. Create a GameStop stock and revenue dashboard.

## 📁 Project Files
- `Revenue Data and Building a Dashboard-v1.ipynb` — Jupyter Notebook containing the code, data extraction, analysis, and visualizations.

## 🚀 How to Run
1. Clone or download this repository.
2. Install the required Python libraries:
   ```bash
   pip install yfinance pandas requests beautifulsoup4 plotly
   ```
3. Open the notebook in Jupyter Notebook or JupyterLab.
4. Run the cells in order to reproduce the analysis and dashboards.

## 📈 Results
The project produces visualizations of historical stock prices and quarterly revenue for Tesla and GameStop, demonstrating practical skills in financial data collection, web scraping, Python data analysis, and data visualization.
